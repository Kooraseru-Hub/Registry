## Registry 1.1.0

Historical release reconstructed from the April 12, 2026 commit explicitly titled Registry v1.1.0 (the pre-release branch revision, before the subsequent merge).

- Hierarchical registration, path aliases and relative lookup.
- Setup, Init, Start and Destroy lifecycle stages, dependencies, categories and priorities.
- Hooks, inspection, error tracking and cleanup helpers.
- Breaking migration from the original context-based API.

The ZIP preserves the original source tree and license; the model preserves the Registry ModuleScript and its nested modules and folders.
