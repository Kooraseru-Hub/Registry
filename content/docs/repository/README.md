# Registry

Registry is a Roblox Luau module manager with path-based registration, dependency ordering, and lifecycle hooks.

Import `source/Registry` into your Roblox project as a ModuleScript tree. Each `init.luau` represents its containing directory. Place the module in `ReplicatedStorage` for shared use or `ServerScriptService` for server-only use.

Download a tagged snapshot from [GitHub Releases](https://github.com/Kooraseru-Hub/Registry/releases). Send contributions to the [source branch](https://github.com/Kooraseru-Hub/Registry/tree/source).
