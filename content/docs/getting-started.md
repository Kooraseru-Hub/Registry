---
title: Install Registry
description: Import Registry into your Roblox experience.
---

Download `Registry.zip` from [GitHub Releases](https://github.com/Kooraseru-Hub/Registry/releases). Import `source/Registry` as a ModuleScript tree, using each `init.luau` as the module for its directory. Put the tree in `ReplicatedStorage` for shared code or `ServerScriptService` for server-only code.
