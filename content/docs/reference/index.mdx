Registry is a Luau ModuleScript library. It exports one constructor-like function, `Register`, which returns a frozen object exposing one method, `Get`.

Unlike Roblox Engine classes, Registry does not expose `Instance` properties, events, or an inheritance hierarchy. This reference lists only members implemented in [the source](https://github.com/Kooraseru-Hub/Registry/blob/source/source/Registry.luau).

## Usage

```luau
--!strict
const Registry = require("@game/ReplicatedStorage/Registry")
const registry = Registry.Register({
    ["Game/Settings"] = script.Parent.Settings,
    ["Game/Ready"] = true,
})

const result, ok = registry:Get("Game/Settings")
if not ok then
    warn(result)
    return
end

print(result)
```

The path parameter is checked against the registration keys. The retrieved result remains `unknown`, so its shape must be checked or narrowed separately.
