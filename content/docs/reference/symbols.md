The API summary uses vector images, not Unicode characters or text surrogates. The member shapes and color categories follow the visual conventions of the [Roblox Creator Hub API reference](https://create.roblox.com/docs/reference/engine/classes/AudioStreamWriter).

The icons in `content/images/api/` are original, simplified SVG drawings of those conventions, not official downloadable Roblox icon assets. They are deliberately local to keep the documentation functional without an external image service. A future replacement with Roblox-distributed assets should first verify that the specific asset license permits redistribution.

Currently Registry has no event or signal members, so the event symbol is reserved but not displayed in the published reference.
