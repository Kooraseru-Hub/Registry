# README badge assets

`sources.json` defines the original ShieldCN renders. The DevForum stars and forks use static, value-only messages; the GitHub README keeps its dynamic counts.

The branch build downloads and sanitizes the original SVGs into the generated main branch at `content/images/badges/*.svg`. No artwork is redrawn. The existing branch build component stages the assets using Lute's native HTTP and filesystem APIs.

The sanitizer rejects executable SVG content and external references. Both the local and Open Cloud branch pipelines inline the sanitized original image bytes as Base64 data URIs in `README.devforum.md`. The checked-in template retains readable asset references and the generated branch retains the SVG files for inspection. The banner keeps its known DevForum upload reference. GitHub's README keeps its original external badges and benchmark layout.

The benchmark carousel similarly uses the exact staged chart bytes. The generated DevForum document can exceed the forum's maximum post length; if it does, upload the chart files and substitute their real forum upload references. The branch builder reports the generated byte count.
